Week 14: Is Your Effect Real?

PS50008A Research Methods | 2-6 February 2026

Author

Gordon Wright

Published

2 February 2026

Overview

NoteThe Complete Inferential Toolkit

This week brings together everything you need to analyse and interpret your results: hypothesis testing to determine IF there’s an effect, confidence intervals to show HOW CERTAIN you are, and effect sizes to show HOW BIG it is.

This week: Learn about null hypothesis significance testing, p-values, t-tests for comparing means, confidence intervals for precision, and effect sizes for practical importance.

Lecture: Wednesday 10:00-12:00 RHBD 143 (2 hours) Lab: Thursday 10:00-12:00 WB304A and WB304B

Learning Objectives

By the end of this week, you will be able to:

Null Hypothesis Significance Testing

  • State the null and alternative hypotheses for a study
  • Explain what a p-value represents (probability of data given H₀)
  • Interpret p-values correctly (and avoid common misconceptions)
  • Apply the significance threshold (α = .05)

Statistical Significance

  • Distinguish between statistical significance and practical importance
  • Understand Type I and Type II errors
  • Explain why we combine p-values with effect sizes and CIs

t-tests

  • Identify when to use an independent samples t-test vs paired samples t-test
  • Conduct both types of t-test in R
  • Report t-test results in APA format
  • Interpret t-test output (t-value, df, p-value)

Confidence Intervals

  • Interpret 95% confidence intervals correctly
  • Understand what CIs tell us about precision and plausible values
  • Use CIs to assess statistical significance (does the CI include zero?)

Effect Sizes

  • Define and calculate Cohen’s d
  • Interpret effect size magnitude (small, medium, large)
  • Explain why effect sizes complement significance testing

Before the Lecture

ImportantRequired Preparation
  1. Read the lecture reading — covers NHST logic, t-tests, CIs, and effect sizes
  2. Review Week 13 content — design choices determine which t-test you use

The Big Picture

This week answers three questions about your results:

TipThe Three Questions
  1. Is it real? — Hypothesis testing and p-values tell us if the effect is likely genuine
  2. How certain are we? — Confidence intervals show the range of plausible values
  3. How big is it? — Effect sizes tell us about practical importance
WarningCritical for Assessments

The t-test is the statistical test you’ll use for your Research Report. You must understand how to choose the right test (from Week 13), interpret results, and report them with effect sizes and CIs.

We’ll use YOUR DataLab data to run actual hypothesis tests:

  • Lab A vs Lab B — Independent samples t-test (between-subjects)
  • Pre vs Post mood — Paired samples t-test (within-subjects)
  • Complete reporting — p-values, CIs, and effect sizes together

Key Concepts

Null Hypothesis Significance Testing (NHST)

  • Null hypothesis (H₀): There is no effect or no difference
  • Alternative hypothesis (H₁): There is an effect or difference
  • p-value: Probability of obtaining results this extreme if H₀ were true
  • Alpha level: Threshold for significance (typically .05)

Making Decisions

  • p < .05: Reject H₀, result is statistically significant
  • p ≥ .05: Fail to reject H₀, result is not statistically significant
  • Type I error: Rejecting H₀ when it’s true (false positive)
  • Type II error: Failing to reject H₀ when it’s false (false negative)

t-tests

Design t-test Type R Function
Between-subjects Independent samples t.test(x, y)
Within-subjects Paired samples t.test(x, y, paired = TRUE)

Confidence Intervals

  • What they show: Range of plausible values for the population parameter
  • 95% CI interpretation: If we repeated the study many times, 95% of CIs would contain the true value
  • CI and significance: If the CI for a difference doesn’t include zero, the result is significant at p < .05
  • Width: Narrower CI = more precision

Effect Sizes (Cohen’s d)

  • What it measures: Difference between means in standard deviation units
  • Benchmarks: Small (0.2), Medium (0.5), Large (0.8)
  • Why important: Statistical significance ≠ practical importance
  • Report both: Always include effect size alongside p-value

APA Reporting

  • Format: t(df) = x.xx, p = .xxx, d = x.xx, 95% CI [x.xx, x.xx]
  • Example: t(48) = 2.34, p = .023, d = 0.67, 95% CI [0.12, 1.22]
  • Include: Test statistic, degrees of freedom, p-value, effect size, CI

## Key Concepts

### Null Hypothesis Significance Testing (NHST)

### t-tests
| Design | t-test Type | R Function |
|--------|-------------|------------|
| Between-subjects | Independent samples | `t.test(x, y)` |
