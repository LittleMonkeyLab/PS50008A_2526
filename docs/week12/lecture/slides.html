The Problem: Raw Data

You collected reaction times from 100 participants.

You now have 100 numbers.

What do you do with them?

We Need to Summarise

Descriptive statistics help us:

1. Compress — From many numbers to meaningful summaries

2. Compare — Groups, conditions, studies

3. Communicate — Share findings clearly

4. Prepare — Set up for statistical tests

Central Tendency

Where is the centre?

Three Measures of Centre

Measure What It Is When to Use
Mean Arithmetic average Normal data, no outliers
Median Middle value Skewed data, outliers
Mode Most frequent Categorical data

The Mean

Mean (\(\bar{x}\)) = Sum of all values ÷ Number of values

\[\bar{x} = \frac{\sum x_i}{n}\]

Mean: Example

Reaction times (ms): 245, 312, 278, 298, 267

\[\bar{x} = \frac{245 + 312 + 278 + 298 + 267}{5}\]

\[\bar{x} = \frac{1400}{5} = 280\text{ms}\]

Mean: Strengths & Weaknesses

Strengths

  • Uses all data
  • Mathematically useful
  • Widely understood

Weaknesses

  • Sensitive to outliers
  • Misleading with skew

The Median

Median = The middle value when data is ordered

Steps:

  1. Sort values low → high
  2. Find the middle value
  3. If even n, average the two middle values

Median: Example

Sorted: 245, 267, 278, 298, 312

The median is 278ms (the middle value)

Median: With Even Numbers

Sorted: 245, 267, 278, 298, 312, 340

Two middle values: 278 and 298

Median = (278 + 298) / 2 = 288ms

The Mode

Mode = The most frequently occurring value

Memory scores: 5, 6, 7, 7, 7, 8, 9

Mode = 7 (appears three times)

Which Measure When?

Quick Rule

If mean ≈ median → data is roughly symmetric

If mean ≠ median → data is likely skewed

Variability

How spread out is the data?

Same Mean, Different Data

  • Dataset A: 48, 49, 50, 51, 52 → Mean = 50
  • Dataset B: 10, 30, 50, 70, 90 → Mean = 50

These are very different!

Variability captures this difference.

The Range

Range = Maximum − Minimum

Dataset A: 52 − 48 = 4

Dataset B: 90 − 10 = 80

Limitation

Range uses only 2 values — very sensitive to outliers

Variance

Variance (\(s^2\)) = Average of squared deviations from the mean

\[s^2 = \frac{\sum (x_i - \bar{x})^2}{n-1}\]

Variance: Step by Step

Data: 245, 312, 278, 298, 267 (Mean = 280)

Step 1: Find the mean ✓

Step 2: Subtract mean from each value (deviation)

Step 3: Square each deviation

Step 4: Sum the squared deviations → Divide by (n−1)

Variance: Calculation

Value Deviation Squared
245 −35 1225
312 +32 1024
278 −2 4
298 +18 324
267 −13 169
Sum 0 2746

Variance = 2746 / 4 = 686.5 ms²

Why n−1?

Degrees of Freedom

We divide by (n−1) because we’re estimating population variance from a sample.

This correction makes our estimate unbiased.

More on this when we cover inference!

Standard Deviation

Standard Deviation (\(s\)) = Square root of variance

\[s = \sqrt{s^2}\]

SD = √686.5 = 26.2ms

Why SD Instead of Variance?

Variance is in squared units (ms²)

SD returns to original units (ms)

Much easier to interpret!

Interpreting SD: The 68-95-99.7 Rule

For normally distributed data:

Within Percentage
1 SD of mean ~68%
2 SD of mean ~95%
3 SD of mean ~99.7%

Example: Reaction Times

Mean = 280ms, SD = 26.2ms

  • ~68% between 254ms and 306ms
  • ~95% between 228ms and 332ms

Distributions

The shape of data

What Is a Distribution?

A distribution shows how values are spread across their possible range.

Visualised as:

  • Histograms
  • Density plots

The Normal Distribution

Normal distribution = Symmetric, bell-shaped curve

Properties:

  • Mean = Median = Mode
  • Defined by mean (location) and SD (spread)
  • Many phenomena approximate this

Skewed Distributions

Positive Skew

  • Tail to the right
  • Mean > Median
  • Example: Income

Negative Skew

  • Tail to the left
  • Mean < Median
  • Example: Age at death

Memory Aid for Skew

The Tail Tells the Tale

The tail points in the direction of the skew name.

Positive skew → tail points to positive (right) side

Bimodal Distributions

Two peaks = Two subgroups

Example: Reaction times might be bimodal if some participants used a different strategy

Identifying Shape: Summary

Shape Mean vs Median Visual
Normal Mean ≈ Median Symmetric bell
Positive skew Mean > Median Tail to right
Negative skew Mean < Median Tail to left
Bimodal Varies Two peaks

Reporting Descriptives

APA format

The Basic Format

Report: (M = value, SD = value)

Participants’ simple reaction times were relatively fast (M = 280ms, SD = 26.2ms).

Comparing Groups

Group A (M = 285ms, SD = 24.1ms) responded faster than Group B (M = 312ms, SD = 31.7ms).

Always Report Both

Critical Rule

The mean without SD is incomplete.

Always report both central tendency AND variability.

Summary

Concept Key Point

Normal Symmetric bell shape
