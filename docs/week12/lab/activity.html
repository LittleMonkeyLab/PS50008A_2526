Q5.5 Why can’t we make causal claims from correlational data?

WarningThe Critical Point: Correlation ≠ Causation

Even if we find a relationship between sleep and memory, we cannot say sleep causes better memory. Why?

  • Maybe healthier people sleep more AND have better memory
  • Maybe motivated students prepare better (sleep AND study)
  • Maybe stress reduces both sleep AND memory

This is why experiments (with manipulation) are needed to establish causation.

TipWhy Statistics Matter

With 28 people, some will get lucky just by chance. If everyone flipped a coin 6 times, someone would get 5 or 6 heads - but that doesn’t mean their coin is biased!

Statistics help us ask: Is this result more extreme than we’d expect from chance alone?

Summary

ImportantKey Concepts from Today

Design Types (See glossary)

Type Same people? IV? Test to use Example
Between-subjects No Yes Independent t-test Memory (Lab A vs B)
Within-subjects Yes Yes Paired t-test Throwing (Dom vs Non-dom)
Correlational N/A No Correlation Sleep & Memory

Variables

  • IV (Independent Variable): What the researcher manipulates or controls
  • DV (Dependent Variable): What the researcher measures

Hypotheses

  • Experimental (H1): Predicts an effect or difference
  • Null (H0): Predicts no effect (any difference is due to chance)
  • One-tailed: Specifies the direction (“A will be greater than B”)
  • Two-tailed: Just predicts a difference (“A and B will differ”)

## Task 1: Reflex Test {.unnumbered}

### What You Did

You caught a falling 30cm ruler five times. The distance you caught it at reflects your reaction time - shorter distance means faster reactions.

### Your Results

```{r}
#| label: reflex-plot
#| fig-height: 4
#| fig-align: center

reflex_cols <- names(reflex)[grep("trial", names(reflex), ignore.case = TRUE)]

if(length(reflex_cols) >= 5) {
  reflex_long <- reflex |>
    select(participant_id, all_of(reflex_cols[1:5])) |>
    pivot_longer(cols = -participant_id, names_to = "trial", values_to = "distance") |>
    filter(!is.na(distance) & distance > 0 & distance <= 30) |>
    mutate(trial_num = as.numeric(str_extract(trial, "\\d+")))
  
  trial_means <- reflex_long |>
    group_by(trial_num) |>
    summarise(mean_dist = mean(distance, na.rm = TRUE), se = sd(distance, na.rm = TRUE)/sqrt(n()))
  
  ggplot(trial_means, aes(x = trial_num, y = mean_dist)) +
    geom_line(colour = coral, linewidth = 1.5) +
    geom_point(colour = coral, size = 4) +
    geom_ribbon(aes(ymin = mean_dist - se, ymax = mean_dist + se), alpha = 0.2, fill = coral) +
    labs(x = "Trial", y = "Mean Distance (cm)", title = "Performance Across Trials") +
    scale_x_continuous(breaks = 1:5) +
    theme(plot.title = element_text(hjust = 0.5, face = "bold", colour = navy))
} else {
  set.seed(42)
  sim <- tibble(trial = 1:5, mean_dist = c(22, 19, 16, 14, 13))
  ggplot(sim, aes(x = trial, y = mean_dist)) +
    geom_line(colour = coral, linewidth = 1.5) + geom_point(colour = coral, size = 4) +
    labs(x = "Trial", y = "Mean Distance (cm)", title = "Performance Across Trials")
}
```

```{r}
#| label: throwing-plot
#| fig-height: 4.5
#| fig-align: center

dom_col <- names(frontallob)[grep("dom.*success|dom.*hit", names(frontallob), ignore.case = TRUE)]
nondom_col <- names(frontallob)[grep("non.*success|non.*hit", names(frontallob), ignore.case = TRUE)]

  throw_long <- throw_data |>
    pivot_longer(cols = c(dom_pct, nondom_pct), names_to = "hand", values_to = "accuracy") |>
    mutate(hand = factor(hand, levels = c("dom_pct", "nondom_pct"), labels = c("Dominant", "Non-Dominant")))
  
  throw_stats <- throw_long |>
    group_by(hand) |>
    summarise(n = n(), Mean = round(mean(accuracy), 1), SD = round(sd(accuracy), 1))
  
  ggplot(throw_long, aes(x = hand, y = accuracy, fill = hand)) +
    geom_boxplot(alpha = 0.6, outlier.shape = NA, width = 0.5) +
    geom_jitter(width = 0.1, size = 3, alpha = 0.7) +
```

### Your Results

```{r}
#| label: sleep-memory-plot
#| fig-height: 4.5
#| fig-align: center

# Get sleep and memory data from merged
sleep_mem <- merged |>
  select(participant_id, sleep_hours, memory_mem_total_1) |>
  filter(!is.na(sleep_hours) & !is.na(memory_mem_total_1) & 
         sleep_hours > 0 & sleep_hours < 15)

if(nrow(sleep_mem) > 5) {
  cor_val <- cor(sleep_mem$sleep_hours, sleep_mem$memory_mem_total_1, use = "complete.obs")
  
  ggplot(sleep_mem, aes(x = sleep_hours, y = memory_mem_total_1)) +
    geom_point(size = 4, colour = navy, alpha = 0.7) +
    geom_smooth(method = "lm", se = TRUE, colour = teal, fill = teal, alpha = 0.2) +

    theme(plot.title = element_text(hjust = 0.5, face = "bold", colour = navy))
} else {
  set.seed(42)
  sim_sleep <- tibble(
    sleep = runif(28, 5, 9),
    memory = 4 + 0.4 * sleep + rnorm(28, 0, 1.2)
  )
  cor_val <- round(cor(sim_sleep$sleep, sim_sleep$memory), 2)
  ggplot(sim_sleep, aes(x = sleep, y = memory)) +
    geom_point(size = 4, colour = navy, alpha = 0.7) +
    geom_smooth(method = "lm", se = TRUE, colour = teal, fill = teal, alpha = 0.2) +
    labs(x = "Hours of Sleep", y = "Words Recalled", 
         title = "Sleep and Memory Performance",
```

`r mcq(c("Between-subjects", "Within-subjects", answer = "Correlational", "Experimental"))`

**Q5.3** What does a positive correlation mean here?

`r mcq(c("Sleep causes better memory", answer = "People who slept more tended to recall more words", "People who slept less recalled more words", "There is no relationship"))`

**Q5.4** Can we say that sleep **causes** better memory based on this data?

`r torf(FALSE)`

**Q5.5** Why can't we make causal claims from correlational data?

`r mcq(c("The sample was too small", "The correlation wasn't strong enough", answer = "Third variables might explain the relationship (e.g., health, motivation)", "Correlations are always meaningless"))`

::: {.callout-warning}
## The Critical Point: Correlation ≠ Causation

Even if we find a relationship between sleep and memory, we **cannot** say sleep *causes* better memory. Why?

- Maybe healthier people sleep more AND have better memory
- Maybe motivated students prepare better (sleep AND study)
- Maybe stress reduces both sleep AND memory

This is why **experiments** (with manipulation) are needed to establish causation.
:::

### Group Discussion Questions

**Q6.1** If someone got 5 out of 6 correct, does that **prove** they have a sixth sense?

`r torf(FALSE)`

**Q6.2** Why not?

`r mcq(c("5/6 is impossible", answer = "Some people will get 5/6 just by luck, even without any real ability", "The experiment was designed wrong", "Sixth sense definitely doesn't exist"))`

`r mcq(c("They definitely have a sixth sense", "They definitely don't have a sixth sense", answer = "Performance is at chance level - consistent with random guessing", "The task was too hard"))`

`r mcq(c("People can detect staring", "People cannot detect staring", answer = "Detection accuracy equals 50% (chance level)", "There is no null hypothesis"))`

::: {.callout-tip collapse="true"}
## Why Statistics Matter

With 28 people, **some will get lucky** just by chance. If everyone flipped a coin 6 times, someone would get 5 or 6 heads - but that doesn't mean their coin is biased!

**Statistics help us ask**: Is this result more extreme than we'd expect from chance alone?

## Key Concepts from Today

**Design Types** (See [glossary](/glossary/design/))

| Type | Same people? | IV? | Test to use | Example |
|------|-------------|-----|-------------|---------|
| [Between-subjects](/glossary/design/between-groups-design.qmd) | No | Yes | Independent t-test | Memory (Lab A vs B) |
| [Within-subjects](/glossary/design/within-groups-design.qmd) | Yes | Yes | Paired t-test | Throwing (Dom vs Non-dom) |
| [Correlational](/glossary/design/correlational-design.qmd) | N/A | No | Correlation | Sleep & Memory |

**Variables**

- [**IV (Independent Variable)**](/glossary/design/independent-variable.qmd): What the researcher manipulates or controls
- [**DV (Dependent Variable)**](/glossary/design/dependent-variable.qmd): What the researcher measures

**Hypotheses**

- **Experimental (H1)**: Predicts an effect or difference
- **Null (H0)**: Predicts no effect (any difference is due to chance)
- **One-tailed**: Specifies the direction ("A will be greater than B")
- **Two-tailed**: Just predicts a difference ("A and B will differ")
:::
