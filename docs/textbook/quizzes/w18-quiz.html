## Instructions

This quiz provides comprehensive practice across all topics covered this term. Work through each investigation carefully, as this mirrors the exam format. Test your ability to identify designs, select appropriate tests, and interpret results.

---

## Part 1: Conceptual Review

### Question 1: Design Types

Match each scenario to its design type:

Different participants in each condition: `r mcq(c(answer = "Between-subjects", "Within-subjects", "Correlational", "Case study"))`

Same participants tested in all conditions: `r mcq(c("Between-subjects", answer = "Within-subjects", "Correlational", "Matched pairs"))`

Measuring the relationship between two variables without manipulation: `r mcq(c("Between-subjects", "Within-subjects", answer = "Correlational", "Experimental"))`

### Question 2: Test Selection

Two independent groups: `r mcq(c(answer = "Independent t-test", "Paired t-test", "Pearson's r", "Chi-square"))`

Same participants, two time points: `r mcq(c("Independent t-test", answer = "Paired t-test", "Pearson's r", "ANOVA"))`

Relationship between two continuous variables: `r mcq(c("Independent t-test", "Paired t-test", answer = "Pearson's r", "Chi-square"))`

### Question 3: Statistical Significance

p < .05 means the result is: `r mcq(c("Definitely true", answer = "Statistically significant at alpha = .05", "Practically important", "100% reliable"))`

p = .08 means: `r mcq(c("Significant at .05", answer = "Not significant at .05", "Definitely no effect", "Large effect"))`

### Question 4: Effect Sizes

Cohen's d = 0.2 is: `r mcq(c(answer = "Small", "Medium", "Large", "Negligible"))`

Cohen's d = 0.5 is: `r mcq(c("Small", answer = "Medium", "Large", "Very large"))`

Cohen's d = 0.8 is: `r mcq(c("Small", "Medium", answer = "Large", "Massive"))`

### Question 5: Correlation Interpretation

r = .65 indicates: `r mcq(c("Weak positive", answer = "Moderate-strong positive", "Weak negative", "Strong negative"))`

r = -.40 indicates: `r mcq(c("Weak positive", "Strong positive", answer = "Moderate negative", "No relationship"))`

### Question 6: Key Concepts

Correlation implies causation: `r torf(FALSE)`

Effect size tells us practical importance: `r torf(TRUE)`

A 95% CI that excludes zero suggests significance at p < .05: `r torf(TRUE)`

## Part 2: Full Investigation Practice

::: {.webex-check .webex-box}

### Investigation 1

A researcher tests whether background music affects concentration. 60 participants are randomly assigned to work in silence or with classical music playing. Concentration is measured using an error-counting task.

1. **Design type:** `r mcq(c(answer = "Between-subjects", "Within-subjects", "Correlational", "Matched pairs"))`

2. **IV:** `r mcq(c(answer = "Background condition (silence vs music)", "Concentration score", "Number of errors", "No IV"))`

3. **DV:** `r mcq(c("Music condition", answer = "Concentration (error count)", "Participant preference", "Room assignment"))`

4. **Appropriate test:** `r mcq(c(answer = "Independent t-test", "Paired t-test", "Pearson's r", "Chi-square"))`

5. **One-tailed hypothesis:** `r mcq(c("Music will affect concentration", answer = "Participants working in silence will make fewer errors than those with music", "There is no effect of music", "Errors and music are correlated"))`

6. **Results: t(58) = 2.34, p = .023, d = 0.61. Significant at alpha = .05?** `r torf(TRUE)`

7. **Effect size:** `r mcq(c("Small", answer = "Medium", "Large", "Not meaningful"))`

:::

::: {.webex-check .webex-box}

### Investigation 2

A researcher measures stress levels before and after a relaxation intervention in 25 participants.

1. **Design type:** `r mcq(c("Between-subjects", answer = "Within-subjects", "Correlational", "Case study"))`

2. **IV:** `r mcq(c(answer = "Time (before vs after relaxation)", "Stress level", "Relaxation technique", "No IV"))`

3. **DV:** `r mcq(c("Time point", answer = "Stress level", "Intervention type", "Participant anxiety"))`

4. **Appropriate test:** `r mcq(c("Independent t-test", answer = "Paired t-test", "Pearson's r", "ANOVA"))`

5. **Results: t(24) = -3.89, p < .001, d = 0.78. The negative t-value indicates:** `r mcq(c("Error in analysis", answer = "Stress decreased (before was higher than after)", "Not significant", "Positive effect"))`

6. **Effect size:** `r mcq(c("Small", answer = "Medium-large", "Very small", "Cannot determine"))`

7. **Conclusion:** `r mcq(c(answer = "Stress significantly decreased after relaxation, medium-large effect", "No change in stress", "Stress increased", "Inconclusive"))`

:::

::: {.webex-check .webex-box}

### Investigation 3

A researcher examines whether screen time is related to sleep quality in 80 teenagers.

1. **Design type:** `r mcq(c("Between-subjects", "Within-subjects", answer = "Correlational", "Quasi-experimental"))`

2. **Is there an IV?** `r mcq(c("Yes, screen time", "Yes, sleep quality", answer = "No IV - both variables are measured", "Yes, age"))`

3. **Appropriate test:** `r mcq(c("Independent t-test", "Paired t-test", answer = "Pearson's r", "Chi-square"))`

4. **Results: r(78) = -.42, p < .001. Direction:** `r mcq(c("Positive", answer = "Negative (more screen time, worse sleep)", "No relationship", "Cannot tell"))`

5. **Strength:** `r mcq(c("Weak", answer = "Moderate", "Strong", "Perfect"))`

6. **Can we conclude screen time CAUSES poor sleep?** `r torf(FALSE)`

7. **Name a possible third variable:** `r mcq(c(answer = "Stress, depression, or poor time management", "The correlation itself", "Sample size", "p-value"))`

:::

::: {.webex-check .webex-box}

### Investigation 4

A researcher compares reaction times between morning people (n=35) and evening people (n=35), tested at 9am.

1. **Design type:** `r mcq(c(answer = "Between-subjects", "Within-subjects", "Correlational", "Repeated measures"))`

2. **IV:** `r mcq(c(answer = "Chronotype (morning vs evening person)", "Reaction time", "Test time", "No IV"))`

3. **DV:** `r mcq(c("Chronotype", answer = "Reaction time", "Time of testing", "Participant preference"))`

4. **Appropriate test:** `r mcq(c(answer = "Independent t-test", "Paired t-test", "Correlation", "Regression"))`

5. **Results: t(68) = 3.12, p = .003, d = 0.75. Effect size:** `r mcq(c("Small", answer = "Medium-large", "Negligible", "Cannot interpret"))`

6. **Morning people had faster reaction times. Is this causal?** `r mcq(c(answer = "We can suggest it, but this is quasi-experimental (chronotype not randomly assigned)", "Yes, definitively causal", "No relationship exists", "Cannot interpret without more data"))`

:::

::: {.webex-check .webex-box}

### Investigation 5

A regression analysis predicts exam performance from hours of revision:
Performance = 45 + 3.5(Hours), R2 = .38

1. **This analysis allows us to:** `r mcq(c("Compare groups", answer = "Predict performance from revision hours", "Determine causation", "Test for differences"))`

2. **The intercept (45) means:** `r mcq(c(answer = "Predicted performance when revision hours = 0", "The slope", "R-squared", "Maximum performance"))`

3. **Each additional hour of revision is associated with:** `r mcq(c("45 more points", answer = "3.5 more points", "38% increase", "No change"))`

4. **If someone revises for 10 hours, predicted performance is:** `r mcq(c("45", "35", "100", answer = "80"))`

5. **R2 = .38 means:** `r mcq(c(answer = "38% of variance in performance is explained by revision", "The correlation is .38", "38% of students improved", "Prediction is 38% accurate"))`

6. **The remaining 62% of variance is:** `r mcq(c(answer = "Due to other factors (ability, sleep, test anxiety, etc.)", "Measurement error only", "Proof the model is wrong", "Impossible to explain"))`

:::

::: {.webex-check .webex-box}

### Investigation 6

A study reports a 95% CI for the mean difference between two groups: [2.5, 8.3].

1. **Does this CI include zero?** `r torf(FALSE)`

2. **This suggests the difference is:** `r mcq(c("Not significant", answer = "Statistically significant at p < .05", "Very large", "Zero"))`

3. **The point estimate for the difference is approximately:** `r mcq(c("2.5", "8.3", answer = "5.4 (midpoint of the interval)", "0"))`

4. **A narrower CI would indicate:** `r mcq(c("Larger effect", answer = "Greater precision in the estimate", "Non-significance", "Smaller sample"))`

5. **If another study found CI [-1.2, 4.8] for the same comparison:** `r mcq(c(answer = "That result would not be significant (CI includes zero)", "Both studies agree", "The effect is larger", "We should average them"))`

:::

## Part 3: Quick-Fire Review

### Research Credibility

Pre-registration helps prevent: `r mcq(c("Participant dropout", answer = "p-hacking and HARKing", "Data collection errors", "Small samples"))`

HARKing means: `r mcq(c("Honest research", answer = "Hypothesising After Results are Known", "High-quality analysis", "Helpful research knowledge"))`

Publication bias refers to: `r mcq(c("Journals being unfair", answer = "Significant results being more likely to be published", "Poor peer review", "Too many publications"))`

### Effect Size vs Significance

A result can be significant but have a small effect size: `r torf(TRUE)`

A large effect size guarantees statistical significance: `r torf(FALSE)`

Effect size is independent of sample size: `r torf(TRUE)`

p-value depends partly on sample size: `r torf(TRUE)`

### Degrees of Freedom

Independent t-test, n1=20, n2=20: df = `r mcq(c("40", answer = "38", "20", "19"))`

Paired t-test, n=30: df = `r mcq(c("30", answer = "29", "28", "60"))`

Correlation, n=50: df = `r mcq(c("50", "49", answer = "48", "100"))`

---

## Summary Checklist

Before the exam, verify you can:

- [ ] Identify design type from any research description
- [ ] Identify IV and DV (or recognise no IV in correlational designs)
- [ ] Select the appropriate statistical test
- [ ] Write one-tailed and two-tailed hypotheses
- [ ] Interpret p-values correctly
- [ ] Interpret effect sizes (small/medium/large)
- [ ] Interpret confidence intervals
- [ ] Interpret regression output (slope, intercept, R2)
- [ ] Explain why correlation does not imply causation
- [ ] Identify questionable research practices

::: {.callout-important}
## Exam Preparation
Review your previous quiz attempts. Focus on areas where you made errors. Practice identifying designs and tests quickly - this is the foundation for all other questions.
:::
