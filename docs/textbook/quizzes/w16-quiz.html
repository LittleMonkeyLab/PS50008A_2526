## Instructions

Test your understanding of regression analysis, the meaning of R-squared, and how we use regression for prediction. Regression builds on correlation to allow us to predict one variable from another.

---

## Part 1: Conceptual Questions

### Question 1: What is Regression?

Simple linear regression is used to:

`r mcq(c("Compare two groups", answer = "Predict one variable from another using a linear equation", "Test for differences before and after", "Determine if variables are categorical"))`

In regression, the predictor variable is also called:

`r mcq(c("The dependent variable", answer = "The independent variable (IV) or X variable", "The outcome", "The residual"))`

The outcome variable is also called:

`r mcq(c("The predictor", answer = "The dependent variable (DV) or Y variable", "The independent variable", "The slope"))`

### Question 2: The Regression Equation

The regression equation is: Y = a + bX. In this equation:

'a' (the intercept) represents:

`r mcq(c("The slope of the line", answer = "The predicted Y value when X = 0", "The correlation coefficient", "The sample size"))`

'b' (the slope) represents:

`r mcq(c("The Y-intercept", answer = "The change in Y for each one-unit increase in X", "The total variance", "The residual"))`

### Question 3: Regression vs Correlation

How is regression different from correlation?

`r mcq(c("They are exactly the same", answer = "Regression allows prediction and has a specific direction (X predicts Y)", "Correlation is more accurate", "Regression only works with experiments"))`

If the correlation between X and Y is strong, the regression will:

`r mcq(c("Fail to work", answer = "Make more accurate predictions", "Always predict perfectly", "Have a slope of zero"))`

### Question 4: R-Squared in Regression

R-squared (R2) tells us:

`r mcq(c("The significance level", answer = "The proportion of variance in Y explained by X", "The slope of the line", "The sample size needed"))`

If R2 = .36, this means:

`r mcq(c("The correlation is .36", "36% of participants showed the effect", answer = "36% of the variance in Y is explained by X", "The prediction is 36% accurate"))`

The remaining variance (1 - R2) is called:

`r mcq(c("Explained variance", answer = "Unexplained or residual variance", "Total variance", "The intercept"))`

### Question 5: Residuals

A residual is:

`r mcq(c("The predicted value", "The slope", answer = "The difference between the actual Y value and the predicted Y value", "The correlation coefficient"))`

If a residual is positive, the actual score was:

`r mcq(c("Lower than predicted", answer = "Higher than predicted", "Exactly as predicted", "Cannot determine"))`

### Question 6: Assumptions of Regression

Linear regression assumes:

`r mcq(c(answer = "A linear relationship between X and Y", "A curvilinear relationship", "No relationship at all", "Categorical variables only"))`

If the relationship is clearly curved (nonlinear), we should:

`r mcq(c("Use linear regression anyway", answer = "Consider transforming variables or using nonlinear methods", "Ignore the pattern", "Collect more data"))`

## Part 2: Interpretation Questions

### Question 7: Interpreting Regression Output

A regression analysis yields: Y = 25 + 3X, R2 = .42

If X = 10, the predicted Y is:

`r mcq(c("25", "30", answer = "55", "42"))`

For every 1-unit increase in X, Y increases by:

`r mcq(c("25", answer = "3", "42", "10"))`

### Question 8: Interpreting R-Squared

Study A reports R2 = .64. Study B reports R2 = .16.

Which study's predictor explains more variance? `r mcq(c(answer = "Study A", "Study B", "They are equal", "Cannot compare"))`

In Study A, what percentage of variance is NOT explained?

`r mcq(c("64%", answer = "36%", "100%", "16%"))`

### Question 9: From Correlation to R-Squared

If r = .60, what is R2?

`r mcq(c(".60", answer = ".36", "6.0", ".30"))`

If r = -.50, what is R2?

`r mcq(c("-.50", "-.25", answer = ".25", ".50"))`

Note: R-squared is always positive because we square the correlation.

### Question 10: Interpreting the Slope

A regression predicting exam score from hours studied shows: Score = 50 + 5(Hours)

This means:

`r mcq(c("Everyone gets 50", answer = "Each additional hour of study is associated with 5 more points", "Studying 5 hours gives a score of 50", "The maximum score is 55"))`

A student who studies 8 hours is predicted to score:

`r mcq(c("58", "50", answer = "90", "80"))`

## Part 3: Application Questions

### Question 11: Making Predictions

A researcher develops a regression equation to predict stress (Y) from workload (X):
Stress = 10 + 2.5(Workload), R2 = .49

For someone with a workload score of 8, predicted stress is:

`r mcq(c("10", "20", answer = "30", "49"))`

How much variance in stress is explained by workload?

`r mcq(c("10%", "25%", answer = "49%", "2.5%"))`

### Question 12: Evaluating Prediction Quality

A regression with R2 = .81 will make:

`r mcq(c("Poor predictions", answer = "Good predictions (81% variance explained)", "Perfect predictions", "No predictions"))`

A regression with R2 = .09 will make:

`r mcq(c("Excellent predictions", answer = "Poor predictions (only 9% variance explained)", "Moderate predictions", "Perfect predictions"))`

### Question 13: Limitations of Prediction

We should be cautious about:

`r mcq(c("Making any predictions", answer = "Predicting beyond the range of observed data (extrapolation)", "Using regression at all", "Large R-squared values"))`

If our data has X values ranging from 1-10, predicting Y when X = 50 is:

`r mcq(c("Very reliable", answer = "Unreliable extrapolation", "More accurate than interpolation", "Impossible"))`

## Part 4: MCQ Exam Practice

::: {.webex-check .webex-box}

### Investigation 1

A researcher examines whether hours of practice predicts piano performance scores. Data from 40 students yields: Performance = 30 + 4(Practice Hours), R2 = .52, p < .001.

1. **What type of analysis is this?** `r mcq(c("t-test", "Correlation only", answer = "Simple linear regression", "ANOVA"))`

2. **Predictor (IV):** `r mcq(c(answer = "Practice hours", "Performance score", "Sample size", "R-squared"))`

3. **Outcome (DV):** `r mcq(c("Practice hours", answer = "Performance score", "The slope", "The intercept"))`

4. **For each additional hour of practice, performance increases by:** `r mcq(c("30 points", answer = "4 points", "52 points", "1 point"))`

5. **A student who practices 10 hours is predicted to score:** `r mcq(c("30", "40", answer = "70", "100"))`

6. **How much variance in performance is explained?** `r mcq(c("30%", "4%", answer = "52%", "70%"))`

:::

::: {.webex-check .webex-box}

### Investigation 2

A study finds that sleep quality (X) predicts daily mood (Y) with R2 = .25.

1. **What percentage of variance in mood is explained by sleep quality?** `r mcq(c("75%", answer = "25%", "50%", "5%"))`

2. **What is the correlation (r) between sleep and mood?** `r mcq(c(".25", answer = ".50 (since R2 = .25, r = sqrt(.25) = .50)", ".75", ".125"))`

3. **What percentage of variance is NOT explained?** `r mcq(c("25%", answer = "75%", "50%", "100%"))`

4. **This unexplained variance could be due to:** `r mcq(c(answer = "Other factors affecting mood (exercise, social contact, stress, etc.)", "Errors in R-squared", "The sample being too large", "Sleep quality being irrelevant"))`

5. **Can we say sleep quality CAUSES better mood?** `r torf(FALSE)`

:::

::: {.webex-check .webex-box}

### Investigation 3

A regression equation is: Test Score = 40 + 0.5(Study Minutes), R2 = .36

1. **The intercept (40) represents:** `r mcq(c(answer = "Predicted score when study time = 0", "The slope", "R-squared", "The maximum score"))`

2. **Studying for 60 minutes predicts a score of:** `r mcq(c("40", "60", answer = "70", "100"))`

3. **Studying for 120 minutes predicts a score of:** `r mcq(c("60", "80", answer = "100", "120"))`

4. **A student actually scored 80 after studying 60 minutes. Their residual is:** `r mcq(c("-10", answer = "+10 (actual 80 minus predicted 70)", "0", "80"))`

5. **The positive residual means they scored:** `r mcq(c(answer = "Higher than predicted", "Lower than predicted", "Exactly as predicted", "We cannot tell"))`

:::

::: {.webex-check .webex-box}

### Investigation 4

A researcher wants to predict job satisfaction from salary. R2 = .15.

1. **How would you evaluate this R2?** `r mcq(c("Excellent - salary fully explains satisfaction", answer = "Modest - salary explains only 15% of variance in satisfaction", "R2 is too small to interpret", "Perfect prediction"))`

2. **What does this suggest about other factors?** `r mcq(c("No other factors matter", answer = "85% of variance is due to other factors (work environment, colleagues, autonomy, etc.)", "Salary is the only factor", "We cannot speculate"))`

3. **Should we conclude salary doesn't matter for satisfaction?** `r mcq(c(answer = "No - it still explains some variance; other factors also matter", "Yes - 15% is too small", "The study is invalid", "We need a larger sample"))`

4. **Multiple regression could help by:** `r mcq(c("Removing the effect of salary", answer = "Including additional predictors to explain more variance", "Making R2 exactly 1.0", "Eliminating residuals"))`

:::

## Summary Checklist

Before moving on, make sure you can:

- [ ] Explain the purpose of regression analysis
- [ ] Interpret the regression equation (Y = a + bX)
- [ ] Understand what the intercept (a) and slope (b) represent
- [ ] Calculate predicted values using a regression equation
- [ ] Interpret R-squared as proportion of variance explained
- [ ] Convert between r and R-squared
- [ ] Explain what residuals represent
- [ ] Recognise limitations of prediction (extrapolation)

::: {.callout-important}
## Key Distinction
Correlation tells us about the strength and direction of a relationship. Regression goes further by providing a specific equation for prediction and quantifying how much variance is explained. However, regression (like correlation) still cannot establish causation without an experimental design.
:::
