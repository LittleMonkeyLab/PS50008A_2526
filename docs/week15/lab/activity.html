## Activity 1: Creating Scatterplots (20 min)

### Visualising Relationships

Before calculating correlations, we should always visualise the relationship with a scatterplot.

```{r}
#| label: frontallob-data
frontallob <- read_csv("task5_frontallob_clean.csv", show_col_types = FALSE)

frontallob_clean <- frontallob |>
  filter(!is.na(self_rating) & !is.na(dom_success))
```

```{r}
#| label: scatterplot-example
#| fig-height: 5
#| fig-align: center
ggplot(frontallob_clean, aes(x = self_rating, y = dom_success)) +
  geom_point(size = 3, colour = navy, alpha = 0.7) +
  geom_smooth(method = "lm", se = TRUE, colour = orange, fill = orange, alpha = 0.2) +
```

## Activity 2: Calculating Correlations (20 min)

### Pearson's r

The Pearson correlation coefficient (r) measures the strength and direction of a **linear** relationship between two continuous variables.

### Properties of r

**1. Pearson's r ranges from:**

`r mcq(c("0 to 1", "-1 to 0", answer = "-1 to +1", "0 to 100"))`

**2. An r value of 0 means:**

`r mcq(c("A perfect positive relationship", "A perfect negative relationship", answer = "No linear relationship", "The calculation failed"))`

**3. An r value of -0.8 indicates:**

`r mcq(c("A weak positive relationship", answer = "A strong negative relationship", "A weak negative relationship", "No relationship"))`

### R Syntax

In R, we calculate correlation using `cor()` or `cor.test()`:

```r
# Simple correlation
cor(variable1, variable2)

# Correlation with p-value and CI
cor.test(variable1, variable2)
```

**4. What is the key difference between `cor()` and `cor.test()`?**

`r mcq(c("cor() is faster", answer = "cor.test() provides a p-value and confidence interval", "cor() gives more decimal places", "They calculate different types of correlation"))`

### Reading R Output

Here's example output from `cor.test()`:

```
    Pearson's product-moment correlation

data:  self_rating and accuracy
t = 3.45, df = 28, p-value = 0.002
alternative hypothesis: true correlation is not equal to 0
95 percent confidence interval:
 0.24  0.75
sample estimates:
      cor
0.55
```

**5. What is the correlation coefficient (r)?**

`r mcq(c("3.45", "0.002", "28", answer = "0.55"))`

**6. Is this correlation statistically significant at alpha = 0.05?**

`r mcq(c(answer = "Yes, because p = 0.002 < 0.05", "No, because the correlation is positive", "Can't tell", "No, because df = 28"))`

**7. The 95% CI is [0.24, 0.75]. What does this tell us?**

`r mcq(c("The correlation is exactly 0.55", answer = "We're 95% confident the true r is between 0.24 and 0.75", "The p-value is between 0.24 and 0.75", "The sample size should be 24 to 75"))`

## Activity 3: Interpreting r Values (20 min)

### Cohen's Guidelines

Jacob Cohen provided rough guidelines for interpreting correlation strength:

| |r| value | Interpretation |
|-----------|----------------|
| 0.10 - 0.29 | Small/weak |
| 0.30 - 0.49 | Medium/moderate |
| 0.50 - 1.00 | Large/strong |

### Practice Interpretation

**1. r = 0.25 would be considered:**

`r mcq(c(answer = "Small/weak", "Medium/moderate", "Large/strong", "Negligible"))`

**2. r = -0.65 would be considered:**

`r mcq(c("Small/weak", "Medium/moderate", answer = "Large/strong", "Not applicable - it's negative"))`

**3. r = 0.42 would be considered:**

`r mcq(c("Small/weak", answer = "Medium/moderate", "Large/strong", "Negligible"))`

### Coefficient of Determination (r-squared)

Squaring r tells us the proportion of variance explained.

**4. If r = 0.50, then r-squared (r^2) equals:**

`r mcq(c("0.50", answer = "0.25", "0.75", "2.5"))`

**5. r^2 = 0.25 means:**

`r mcq(c(answer = "25% of the variance in Y is explained by X", "The correlation is 25%", "75% of participants show the relationship", "The effect is 25% larger than expected"))`

**6. If r = 0.70, what percentage of variance is explained?**

`r mcq(c("70%", answer = "49%", "30%", "100%"))`

### Critical Thinking

**7. A statistically significant correlation of r = 0.15 suggests:**

`r mcq(c("A strong, important relationship", answer = "A real but very weak relationship - likely not practically meaningful", "The data is unreliable", "We need to use a different test"))`

True or False: A significant p-value tells us the correlation is strong. `r torf(FALSE)`

True or False: Correlation does not imply causation. `r torf(TRUE)`

True or False: A negative correlation is weaker than a positive correlation of the same magnitude. `r torf(FALSE)`

## Summary

::: {.callout-important}
## Key Takeaways

**Scatterplots:**
- Always visualise before calculating
- Each point = one participant
- Look for patterns, linearity, and outliers

**Pearson's r:**
- Ranges from -1 to +1
- Sign indicates direction (positive/negative)
- Magnitude indicates strength

**Interpretation:**
- Small: |r| = 0.10 - 0.29
- Medium: |r| = 0.30 - 0.49
- Large: |r| = 0.50+
- r^2 = proportion of variance explained

**Cautions:**
- Correlation does NOT equal causation
- Watch for third variables
- Statistical significance does not equal practical importance
:::
