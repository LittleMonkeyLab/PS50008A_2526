Research Methods Glossary

Key concepts, statistical methods, and DataLab activities

Browse All Glossary Items

Use the category sidebar to filter by topic, or search and sort using the controls below.

Term Category Definition
Between-Groups Design Design Different participants are assigned to each experimental condition
Choosing a Statistical Test Analysis A decision guide for selecting the appropriate statistical test
Confounding Variable Design A variable that systematically varies with the IV, threatening causal inference
Control Condition Design The condition where the causal variable is absent, providing a baseline for comparison
Correlation Analysis A measure of the strength and direction of the relationship between two variables
Correlational Design Design Measures the relationship between variables without manipulation
Counterbalancing Design Systematically varying the order of conditions to control for order effects
Demographics & Baseline Measures DataLab Participant background information and TIPI personality collected at DataLab
Dependent Variable Design The variable measured; the outcome or effect
Directional Hypothesis Statistics Specifies the direction of the predicted difference or relationship
Dispersion Statistics How spread out the data are around the central value
Effect Size Statistics A standardised measure of the magnitude of an observed effect
Experimental Condition Design The condition where the causal variable of interest is present
Experimental Hypothesis Statistics Predicts that the IV will affect the DV
Extraneous Variable Design An uncontrolled variable that may affect the results
Independent Variable Design The variable manipulated by the researcher; the presumed cause
Independent t-test Analysis Compares means between two separate groups of participants
Interval Data Statistics Numerical data with equal intervals but no true zero point
Levels and Conditions Design The different values or states of the independent variable being compared
Levels of Measurement Statistics The four scales of measurement that determine appropriate statistics
Mann-Whitney U Test Analysis Non-parametric test comparing distributions between two independent groups
Matched Participants Design Design Pairs of similar participants are matched and randomly assigned to conditions
Mean Statistics The arithmetic average of a set of values
Median Statistics The middle value when data are ordered from lowest to highest
Mixed Design Design Combines within-groups and between-groups factors in one experiment
Mode Statistics The most frequently occurring value in a dataset
Nominal Data Statistics Categorical data with no inherent order or ranking
Non-directional Hypothesis Statistics Predicts a difference without specifying the direction
Null Hypothesis Statistics Predicts no effect of the IV on the DV
Operationalisation Design Defining abstract concepts in terms of specific, measurable procedures
Order Effects Design Changes in performance due to the sequence of conditions in within-groups designs
Ordinal Data Statistics Ranked data where the intervals between values are not necessarily equal
Paired t-test Analysis Compares two related means from the same participants
Pearson’s r Analysis Parametric correlation coefficient for interval/ratio data
Practice Effect Design Improvement in performance due to repeated exposure or familiarity with a task
Pre-Post Survey DataLab Within-subjects mood tracking before and after DataLab stations
Random Assignment Design Allocating participants to conditions using chance to control for confounds
Range Statistics The difference between the highest and lowest values
Ratio Data Statistics Numerical data with equal intervals and a true zero point
Scatterplot Analysis A graph showing the relationship between two continuous variables
Significance Level Statistics The threshold probability for rejecting the null hypothesis, typically set at .05
Spearman’s rho Analysis Non-parametric correlation coefficient based on ranks
Standard Deviation Statistics The average distance of scores from the mean
Station 1: Reflex Test DataLab Measure reaction time using a ruler-drop task
Station 2: Mind Palace DataLab Memory test exploring serial position effect and word type
Station 3: Time Warp DataLab Time and magnitude estimation tasks
Station 4: Sixth Sense DataLab Signal detection test - can you sense when someone is watching?
Station 5: Lady Luck DataLab Human randomness perception and cognitive biases
Station 6: Frontal Lob DataLab Metacognition and calibration - self-prediction vs actual performance
Type I Error Statistics Rejecting the null hypothesis when it is actually true (false positive)
Type II Error Statistics Failing to reject the null hypothesis when it is actually false (false negative)
Variable Design Something that varies; can have different values or levels
Variance Statistics The average squared deviation from the mean
Wilcoxon Signed-Rank Test Analysis Non-parametric test comparing two related samples
Within-Groups Design Design Each participant experiences all conditions of the experiment
p-value Statistics The probability of obtaining results at least as extreme as observed, assuming the null hypothesis is true
