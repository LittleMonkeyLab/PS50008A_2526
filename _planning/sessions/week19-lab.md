## Outcomes
P8, P9, P10, R4

## One-liner
Project analysis workshop: troubleshooting, interpretation, and results write-up support.

## Paragraph


## Activity structure
- 0-15 min: Common analysis issues—brief whole-class troubleshooting
- 15-60 min: Workshop—individual/group support, circulating help

## Skills practised
- P8: Using R for final project analysis
- P9: Checking and reporting assumptions
- P10: Writing results in APA format
- R4: Interpreting and reporting findings

## Data used
Project data

## Software and tools
- R for analysis
- APA template from lecture

## Instructions for students
Bring your analysis to the lab. Use this time to:
1. Finalize any incomplete analyses
2. Check assumptions you haven't checked
3. Draft your results section
4. Get feedback on interpretation

## Deliverable
Draft results section for project (not graded, but strong preparation for week 22).

## Common problems
- Last-minute discovery of assumption violations
- Uncertainty about how to report non-significant results
- Interpretation overreach (claiming causation from correlation)
- R errors from code written weeks ago

## Demonstrator notes
This is workshop format—no structured teaching. Circulate actively. Prioritize students who are stuck over those who are cruising. Encourage peer support.

## Project time
Entire lab is project-focused. Students should leave with analysis complete and results section drafted.
