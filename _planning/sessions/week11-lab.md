## Outcomes
C1, C8, R2, R4, R8

## One-liner
Students generate the dataset they'll analyse all term through six rotating stations mixing cognitive tasks with interactive group activities.

## Paragraph
The Data Olympics introduces core concepts through activity rather than instruction. Students rotate through six stations in pairs—three screen-based (reaction time, estimation, cognitive task) and three behavioural (wall estimation, paired memory, group consensus). Two parallel labs run identical protocols, creating a natural null hypothesis. By session end, we have 60+ rows of real, messy human data.

## Activity structure
- 0-5 min: Brief orientation, ID assignment, pair formation
- 5-65 min: Six stations, 10 mins each, signal to rotate
- 65-75 min: Data entry/cleanup for paper-based tasks, first look at distributions

## Skills practised
- Following standardised protocols
- Being participant and tester
- Recording data systematically
- Working in pairs

## Data used
Generated in session—this IS the Data Olympics

## Software and tools
- Qualtrics or MS Forms for screen tasks (RT, estimation, cognitive)
- Shared Google Sheet for paper-based data entry
- Timer/signal for rotations

## Instructions for students
Passport card with ID code, room code, station order. Screen tasks auto-record; behavioural tasks recorded on paper then entered at end.

## Deliverable
Complete data record in shared spreadsheet. All stations completed.

## Common problems
- Students skip stations or do them out of order
- Paper data entry errors
- Screen tasks not saving (check ID entered correctly)
- Time pressure at rotations

## Demonstrator notes
- Run identical protocol to other room—this matters for later analysis
- Signal rotations clearly and loudly
- Circulate to troubleshoot, don't cluster at one station
- Capture photos of wall estimation line-ups (with consent)

## Project time
Final 10 mins: form project groups, exchange contact details

## Station details (to be expanded)

### Screen-based (individual)
1. **Reaction time**: Simple RT + choice RT, 5 trials each, record mean
2. **Estimation battery**: Beans, line length, tone duration, dot count + confidence ratings
3. **Cognitive task**: Backwards digit span OR Stroop variant

### Behavioural (paired/group)
4. **Estimation wall**: Stand on 0-100 line for questions read aloud, record positions
5. **Paired memory**: One reads 15 words, other recalls after 30s, swap roles
6. **Group consensus**: Private estimate of string length, then group agreement, record both
