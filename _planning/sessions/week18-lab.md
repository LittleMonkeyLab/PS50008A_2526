## Outcomes
All C outcomes (practice), P4, P5, P6, P8

## One-liner
MCQ practice and project analysis support.

## Paragraph


## Activity structure
- 0-30 min: MCQ practice—work through investigations individually then discuss
- 30-60 min: Project analysis time—supported troubleshooting

## Skills practised
- MCQ decision process under time pressure
- Project analysis completion
- P8: Using R for project data

## Data used
Practice MCQ materials; project data

## Software and tools
- Practice MCQ handout
- R for project analysis

## Instructions for students
Part 1: Complete practice investigations. Time yourself. Check answers. Identify weak areas.

Part 2: Work on project analysis. Get help with any stuck points.

## Deliverable
Self-assessed MCQ practice. Project analysis progress.

## Common problems
- MCQ: Rushing without using the decision flowchart
- MCQ: Second-guessing correct answers
- Project: Last-minute analysis panic

## Demonstrator notes
Split time between MCQ support and project support. For MCQ, encourage students to articulate *why* they chose each answer. For projects, this is the last chance for substantial analysis help.

## Project time
30 mins minimum for project support. Analysis should be complete or finalized by end of session.

## Assessment note
**MCQ Exam (20%) this week.** Lab provides final practice opportunity and project support.
