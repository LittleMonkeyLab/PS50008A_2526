## EDS format reminder
Section A (statistical mechanics):
1. State hypothesis
2. Identify design, IV, DV, data type
3. Calculate means and SDs BY HAND
4. Run appropriate test BY HAND (show all steps)
5. Interpret results

Section B (methods and theory):
6. Two methodological improvements
7. Individual differences discussion
8. Ecological validity proposal (half page minimum)
