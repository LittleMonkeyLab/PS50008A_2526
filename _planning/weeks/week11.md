## Week summary
Students generate the dataset they will analyse throughout the term via the Data Olympics—six rotating stations mixing screen-based cognitive tasks with interactive group activities. Two parallel labs run identical protocols, creating a natural null hypothesis for later comparison.

## Key concepts introduced

- Variables as things that vary
- Sampling variability (implicit—two rooms, same protocol, different results?)
