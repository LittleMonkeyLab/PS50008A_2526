## Week summary
Estimation-first approach: what's our best guess, and how uncertain are we? Bootstrap confidence intervals make sampling variability visible. Effect sizes as "how big is this in real terms?"

## Key concepts introduced
- Point estimates vs interval estimates
- Confidence intervals (bootstrap intuition, then formula)
- Effect size (Cohen's d for differences)
- Sample size and precision relationship [C19]

## Skills developed
- Interpret CIs: "we're 95% confident the true value is between..."
- Build bootstrap CIs in WebR (visual, not formula-heavy)
- Report effect sizes
