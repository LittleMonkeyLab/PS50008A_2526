## SESSION TIMELINE

### 0:00 - 0:15 | WELCOME & SETUP (15 min)

| Time | Action | Script |
|------|--------|--------|
| 0:00 | Greet arrivals | Hand out numbered cards as students enter |
| 0:03 | Start session | "Welcome to DataLab! Today you'll generate your own psychology dataset." |
| 0:05 | Form groups | "Find others with the same card colour - that's your group for today." |
| 0:08 | Survey intro | "Scan the QR code and complete Part 1. This takes about 7 minutes." |
| 0:15 | Check completion | Ensure all have finished Part 1 before starting rotations |

**Part 1 Survey Contents:**
- Consent
- Participant ID & Lab room
- Group colour
- Sleep & Lifestyle
- Mood PRE (baseline)
- TIPI (10 items)
- Basic demographics

---

### 0:15 - 1:45 | STATION ROTATIONS (90 min)

**Rotation Schedule (12-15 min per station)**

| Time | Bell | Note |
|------|------|------|
| 0:15 | 🔔 START | Groups 1-6 to stations, Groups 7-8 buffer time |
| 0:30 | 🔔 ROTATE | Move clockwise |
| 0:45 | 🔔 ROTATE | Groups 7-8 join rotation |
| 1:00 | 🔔 ROTATE | Midpoint - energy check |
| 1:15 | 🔔 ROTATE | |
| 1:30 | 🔔 ROTATE | Final rotation |
| 1:45 | 🔔 END | All return to home base |

**Facilitator Responsibilities During Rotations:**
1. **Circulate** - Visit each station to assist/answer questions
2. **Time** - Give 2-minute warning before each bell
3. **Monitor** - Ensure data is being recorded
4. **Assist** - Help solo participants at Station 4

**Station-Specific Notes:**

| Station | Facilitator Role | Watch For |
|---------|-----------------|-----------|
| 1: RT | Minimal - student-led | Proper technique (0cm alignment), recording in CM |
| 2: Memory | Time the phases | Peeking during distraction |
| 3: Time | YOU run the 60-sec timer | Lab B: Start music; Strings: eyes closed |
| 4: Staring | Monitor randomisation | Solo participants need video |
| 5: Randomness | Minimal - student-led | Number generation done aloud |
| 6: Motor | Minimal - student-led | Correct throwing line |

---

### 1:45 - 1:55 | PART 2 SURVEY (10 min)

| Time | Action | Script |
|------|--------|--------|
| 1:45 | Gather | "Everyone back to home base for Part 2!" |
| 1:47 | Survey | "Complete the final section of the survey - mood questions and feedback." |
| 1:55 | Check | Ensure all surveys submitted |

**Part 2 Survey Contents:**
- Mood POST (for pre-post comparison)
- Session feedback
- Favourite/least favourite station
- Comments

---

### 1:55 - 2:00 | DEBRIEF (5 min)

**Key Points to Cover:**

1. **Thank them** - "You've just generated your own dataset!"

2. **Preview analysis** - "Over the coming weeks, we'll analyse this data together. You'll see patterns in your own performance."

3. **Between-lab reveal** - "Lab A and Lab B had one key difference at Station 3. We'll discover what effect that had when we look at the data."

4. **Questions** - Brief Q&A

5. **Dismiss** - "Thanks for participating in DataLab!"

## QUICK TROUBLESHOOTING

| Issue | Solution |
|-------|----------|
| WiFi down | Have paper backup surveys ready |
| Student arrives late | Assign to smallest group or solo |
| Station equipment breaks | Swap with spare; skip if necessary |
| Student feels unwell | Excuse to home base; partial data OK |
| Time running over | Cut final rotation short; prioritise Part 2 |
| Solo at Station 4 | Use video version or pair with another solo |
